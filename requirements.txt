# ==========================================================================
#  Psi Core · dependencias del backend
# ==========================================================================
#  Instalación:
#      python -m venv venv
#      venv\Scripts\activate            (Windows)
#      pip install -r requirements.txt
#
#  Para EMPAQUETAR la aplicación de escritorio (.exe), además:
#      pip install -r requirements-desktop.txt
#
#  Regla que se sigue aquí: **todo lo que el código importa está declarado**,
#  aunque pip ya lo instale como dependencia de otro paquete. Depender de una
#  dependencia transitiva funciona hasta el día en que el paquete de arriba
#  cambia su árbol, y entonces la aplicación se rompe sin que nadie haya
#  tocado nada.
# ==========================================================================
